# DeciLog – Collaborative Decision Log System

**DeciLog** is a web-based Collaborative Decision Log System built as a Software Engineering minor project.  
It helps teams record important decisions with full context, track their outcomes, and learn from past choices.

---

## Features

- User Registration & Login (with role support)
- Create, View, Edit & Delete Decisions
- Structured Decision Recording:
  - Context / Problem Statement
  - Alternatives Considered
  - Chosen Option
  - Rationale
  - Status, Tags & Related Project
- Outcome Tracking (Good / Neutral / Bad + Lessons Learned)
- Comments on Decisions
- Dashboard with key statistics
- Analytics (Status distribution + Outcome summary)
- Search & Filter decisions
- Clean and responsive UI (Bootstrap 5)

---

## Tech Stack

- **Language**: Python 3
- **Framework**: Flask
- **Database**: SQLite + SQLAlchemy
- **Authentication**: Flask-Login
- **Forms**: Flask-WTF
- **Frontend**: HTML5 + Bootstrap 5 + Bootstrap Icons
- **Styling**: Custom CSS
